# Moonwalk for brainrots

Roblox project scaffold aligned with the approved architecture:

- Rojo-based source sync (`default.project.json`)
- Wally for package management (`wally.toml`)
- StyLua + Selene quality baseline
- Domain-structured source tree for Server/Client/Shared

## Quick Start

1. Install Roblox Studio, Rojo, and Wally.
2. Open this folder in your editor.
3. Sync with Roblox Studio using Rojo.

## Quality Commands

- `stylua .`
- `selene src`
